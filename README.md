# ソシャゲ風ロビー（Gacha Lobby）

自分の VRM アバターを、ソシャゲ風のロビー画面に立たせるキットです。
雨上がりの夜、サイバーパンクな屋上に立つキャラを、望遠のカメラが引きと顔アップで交互に映します。

背景、カメラワーク、ポーズ、風、UI、動画の書き出しまで全部入っています。最初はサンプルの「白雪 ルナ」で動きます。
自分のキャラに入れ替えるのは、エージェント（Claude Code や Codex）に頼むだけです。

## 開き方

1. Node.js 22 以上を入れておく
2. `ロビーを開く.bat` をダブルクリック（Windows 以外は `node serve.mjs`）
3. ブラウザでロビーが開く（ふつうは `http://127.0.0.1:8777/`。使用中なら次の番号で開き、黒い画面に表示されます）

操作: `P` ポーズ切替 ／ `C` シーン切替 ／ `H` UI を隠す。URL に `?ui=0`（UI なし）、`?pose=lean`（最初のポーズ）なども付けられます。

## 自分のキャラに入れ替える

エージェントに、たとえば次のように頼んでください。

> skills/lobby-character を読んで、私のアバター（〇〇.vrm）をロビーに入れて

エージェントがブラウザを操作できる必要があります（ブラウザを使えないエージェントはサポート外です）。

VRM を置いて名前を書くだけの作業なので、多少崩れていてもまず動く状態にしてくれます。
気になる所があれば、続けて頼めば直してくれます（ポーズの手の位置、明るさ、セルルックにする、動画を書き出す、など）。

手で入れ替える場合:

1. `app/characters/<好きな名前>/` を作り、VRM（例: `avatar.vrm`）を置く
2. 同じフォルダに `character.json` を書く（`app/characters/luna/character.json` が見本）
3. `app/lobby.local.json` を作り、`{"character": "<フォルダ名>"}` と書く（自分用の設定。git には入りません。無ければ `app/lobby.json` のルナが出ます）

## 見た目の種類

| 種類 | 内容 |
|---|---|
| MToon（標準） | VRM の見た目のまま、ロビーの夜の光（青白い主光、紫の環境光、マゼンタの輪郭光）に合わせる |
| セルルック（オプション） | ルナと同じ、影がくっきり1段のアニメ調。エージェントに `skills/lobby-cel` を読んでもらって作る |

## 動画の書き出し

サーバーを起動した状態で:

```bash
node tools/record.mjs lookback 60 out/lobby.mp4 1920 1080
```

ポーズは `lookback`・`lean`・`chest`・`behind`。サーバーが開いた番号は自動で読みます。Google Chrome と ffmpeg が必要です（Chrome の場所が違うときは環境変数 `CHROME` で指定）。1コマずつ撮るので、コマ落ちしません。最初の約13秒は引きのカットなので、顔アップまで入れるなら15秒以上にしてください。

## フォルダ

```
serve.mjs / ロビーを開く.bat   起動
app/lobby.html               ページ本体
app/lobby/                   ステージ・カメラ・ポーズ・UI・風・後処理
app/stage/                   背景の素材（Tripo で生成）と配置（assets.json）
app/characters/luna/         サンプルキャラ（VRM、セルルックのデータ、ルナ専用のエフェクト）
app/characters/<自分のキャラ>/ 入れ替えたキャラ（リポジトリには入らない）
skills/                      エージェント用の手順（入れ替え、セルルック）
tools/record.mjs             動画の書き出し
```

## 利用条件

- **白雪 ルナのモデル**: 改変 OK・再配布 NG・商用利用 NG・クレジット表記が必要（「白雪 ルナ / Nano」）。このキットに入った形で使うのはかまいませんが、モデルだけを取り出して配布しないでください。
- **背景の素材**（`app/stage/` のビル・車・床・遠景の画像）: [Tripo](https://www.tripo3d.ai/) で生成した AI 生成物です。このキットの中で自由に使い、改変してかまいません。
