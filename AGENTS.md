# Gacha Lobby — for agents

- Swapping the character, renaming it, recording a video: read `skills/lobby-character/SKILL.md`.
- Optional cel-shaded look: read `skills/lobby-cel/SKILL.md`.
- You need a browser you can drive to look at the page (agents without one are not supported).
- Reply to the user in the language they write in.
